📝 Методы строк

Метод Описание Пример Результат
upper() Верхний регистр "hello".upper() "HELLO"
lower() Нижний регистр "HELLO".lower() "hello"
capitalize() Первая буква заглавная "hello".capitalize() "Hello"
strip() Убрать пробелы по краям " hi ".strip() "hi"
find(x) Найти индекс подстроки "hello".find("ll") 2
count(x) Подсчитать вхождения "hello".count("l") 2
replace(a, b) Заменить a на b "hello".replace("l", "r") "herro"
split(sep) Разбить по разделителю "a,b".split(",") ['a', 'b']
join(list) Собрать список в строку "-".join(['a', 'b']) "a-b"

📋 Методы списков

Метод Описание Пример Результат
append(x) Добавить элемент в конец [1,2].append(3) [1, 2, 3]
extend(list) Добавить несколько элементов [1].extend([2,3]) [1, 2, 3]
insert(i, x) Вставить по индексу [1,3].insert(1, 2) [1, 2, 3]
remove(x) Удалить по значению [1,2,3].remove(2) [1, 3]
pop(i) Удалить по индексу [1,2,3].pop(1) [1, 3]
sort() Сортировка [3,1,2].sort() [1, 2, 3]
reverse() Перевернуть список [1,2,3].reverse() [3, 2, 1]
index(x) Найти индекс элемента [10,20,30].index(20) 1
count(x) Подсчитать вхождения [1,2,2,3].count(2) 2
clear() Очистить список [1,2,3].clear() []

📚 Методы словарей

Метод Описание Пример Результат
get(key, default) Безопасное получение d.get("x", 0) Значение или default
keys() Все ключи {"a":1}.keys() dict_keys(['a'])
values() Все значения {"a":1}.values() dict_values([1])
items() Все пары ключ-значение {"a":1}.items() dict_items([('a', 1)])
update(dict) Добавить/обновить пары d.update({"b":2}) Добавляет ключи
pop(key) Удалить и вернуть значение {"a":1}.pop("a") 1
del d[key] Удалить по ключу del d["a"] Удаляет ключ

Методы множеств

Метод/Операция Описание Пример Результат
add(x) Добавить элемент {1,2}.add(3) {1, 2, 3}
remove(x) Удалить (ошибка если нет) {1,2}.remove(2) {1}
discard(x) Удалить (без ошибки) {1,2}.discard(5) {1, 2}
union() или | Объединение {1,2} | {2,3} {1, 2, 3}
intersection() или & Пересечение {1,2} & {2,3} {2}
difference() или - Разность {1,2} - {2,3} {1}
symmetric_difference() или ^ Симметрическая разность {1,2} ^ {2,3} {1, 3}
issubset() Проверка подмножества {1}.issubset({1,2}) True
clear() Очистить множество {1,2}.clear() set()
