📟 Tkinter: графические интерфейсы

Основы

Команда Описание Пример
import tkinter as tk Импорт библиотеки import tkinter as tk
tk.Tk() Создать главное окно window = tk.Tk()
window.title("...") Заголовок окна window.title("Моё окно")
window.geometry("WxH") Размер окна (ширина x высота) window.geometry("400x300")
window.mainloop() Запустить окно (держать открытым) window.mainloop()

Виджеты

Виджет Описание Пример
Label Текстовая метка tk.Label(window, text="Привет")
Entry Поле ввода (одна строка) tk.Entry(window, width=30)
Button Кнопка tk.Button(window, text="OK")
Text Многострочное поле ввода tk.Text(window, width=40, height=10)
Radiobutton Переключатель (выбор одного) tk.Radiobutton(window, text="Да", variable=var, value="yes")
Checkbutton Флажок (да/нет) tk.Checkbutton(window, text="Согласен", variable=var)
Listbox Список элементов tk.Listbox(window)

Методы виджетов

Метод Описание Пример
.pack() Разместить виджет (по умолчанию) label.pack()
.grid(row, column) Разместить в сетке label.grid(row=0, column=1)
.place(x, y) Разместить по координатам label.place(x=50, y=100)
.config(...) Изменить свойства виджета label.config(text="Новый", fg="red")
.get() Получить текст (Entry) text = entry.get()
.insert(pos, text) Вставить текст (Entry/Text) entry.insert(0, "Привет")
.delete(start, end) Удалить текст entry.delete(0, "end")
