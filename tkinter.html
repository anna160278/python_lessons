✅ Что такое GUI и первое окно

До сих пор наши программы общались с пользователем через текст в консоли: input() спрашивает, print() отвечает. Это работает, но выглядит скучно.

GUI (Graphical User Interface) — это графический интерфейс: окна, кнопки, поля ввода. Всё, к чему ты привык в играх и приложениях.

💡 Консоль vs GUI:

🖥️Консоль: чёрное окно, только текст

️📟GUI: цветные окна, кнопки, картинки, мышка

Библиотека tkinter

В Python есть встроенная библиотека tkinter для создания GUI. Она уже установлена — ничего дополнительно скачивать не нужно!

import tkinter as tk # Создаём главное окно window = tk.Tk() window.title("Моё первое окно") window.geometry("400x300") # ширина x высота window.mainloop() # запускаем окно
🔑 Что здесь происходит:

tk.Tk() — создаёт окно (как Car() создаёт объект машины)

title() — задаёт заголовок окна

geometry() — задаёт размер в формате "ширинаxвысота"

mainloop() — запускает окно и держит его открытым (как бесконечный цикл)

Первый виджет: Label (текст)

Виджет — это элемент интерфейса: текст, кнопка, поле ввода. Самый простой виджет — Label (метка/текст).

import tkinter as tk window = tk.Tk() window.title("Привет!") # Создаём текст label = tk.Label(window, text="Привет, мир!") label.pack() # размещаем в окне window.mainloop()
💡 Как работает Label:

tk.Label(window, text="...") — создаём текст

Первый аргумент — родитель (окно, в котором будет текст)

text= — что написать

pack() — размещает виджет в окне (по умолчанию — сверху)

🔘 Entry, Button и свойства виджетов

Теперь добавим поле ввода (Entry) и кнопку (Button). Также разберём, как менять внешний вид виджетов.

Виджет Entry (поле ввода)

Entry — это однострочное поле, куда пользователь может вводить текст. У него есть три важных метода:

import tkinter as tk window = tk.Tk() entry = tk.Entry(window, width=30) entry.pack() # get() — получить текст из поля text = entry.get() print(text) # то, что ввёл пользователь # insert() — вставить текст в поле entry.insert(0, "Привет!") # вставить в начало # delete() — удалить текст entry.delete(0, "end") # удалить всё (от 0 до конца) window.mainloop()
🔑 Методы Entry:

entry.get() — получить текст, который ввёл пользователь (возвращает строку)

entry.insert(0, "текст") — вставить текст. 0 — позиция вставки (0 = начало)

entry.delete(0, "end") — удалить текст. 0 — откуда, "end" — до конца

entry.delete(0) — удалить один символ в позиции 0

Наглядный пример: Приветствие

Давай сделаем программу, где пользователь вводит имя, нажимает кнопку — и видит приветствие:

import tkinter as tk window = tk.Tk() window.title("Приветствие") # Функция, которая сработает при клике def say_hello(): name = entry.get() # 1. Получаем текст из Entry if name: # 2. Проверяем, не пустое ли поле label.config(text=f"Привет, {name}! 👋") # 3. Меняем текст Label entry.delete(0, "end") # 4. Очищаем поле ввода else: label.config(text="Введи имя!") # Создаём виджеты entry = tk.Entry(window, width=30) entry.pack(pady=10) button = tk.Button(window, text="ОК", command=say_hello) button.pack(pady=10) label = tk.Label(window, text="", font=("Arial", 14)) label.pack(pady=10) window.mainloop()
💡 Как это работает (по шагам):

1️⃣ Пользователь вводит имя → текст сохраняется в Entry

2️⃣ Нажимает кнопку → вызывается функция say_hello()

3️⃣ entry.get() → получаем текст из поля (например, "Аня")

4️⃣ label.config(text=...) → меняем текст метки на "Привет, Аня! 👋"

5️⃣ entry.delete(0, "end") → очищаем поле для нового ввода

Свойства виджетов

У каждого виджета есть свойства, которые задаются при создании:

# Label с разными свойствами label = tk.Label( window, text="Красивый текст", font=("Arial", 16), # шрифт и размер fg="blue", # цвет текста (foreground) bg="yellow", # цвет фона (background) width=20, # ширина height=2 # высота ) label.pack()
🎨 Популярные свойства:

text — текст (для Label и Button)

font — шрифт: ("Arial", 16) или ("Times", 12, "bold")

fg — цвет текста (foreground)

bg — цвет фона (background)

width, height — размеры

relief — стиль рамки: "flat", "raised", "sunken"

Отступы: padx и pady

Чтобы виджеты не прилипали друг к другу, используем отступы:

label.pack(padx=20, pady=10) # padx — отступы слева и справа # pady — отступы сверху и снизу

️ Изменение свойств и обработка событий

Виджеты можно менять после создания — через метод config(). А кнопки могут запускать функции через параметр command.

Метод config() — меняем свойства

import tkinter as tk window = tk.Tk() label = tk.Label(window, text="Старый текст") label.pack() # Меняем текст и цвет label.config(text="Новый текст!", fg="red") window.mainloop()

Параметр command — что делает кнопка

Когда пользователь нажимает кнопку, должна выполниться какая-то функция. Её указываем в параметре command:

def on_click(): print("Кнопка нажата!") button = tk.Button( window, text="Нажми", command=on_click # без скобок! ) button.pack()
️ Важно:

command=on_click — передаём имя функции (без скобок!)

command=on_click() — ошибка! Это вызовет функцию сразу при создании кнопки

Получение данных из Entry

Чтобы узнать, что пользователь ввёл в поле, используем метод get():

def show_name(): name = entry.get() # получаем текст из поля label.config(text=f"Привет, {name}!") entry = tk.Entry(window) entry.pack() button = tk.Button(window, text="OK", command=show_name) button.pack() label = tk.Label(window, text="") label.pack()
🔑 Запомни:

entry.get() — получить текст из поля ввода

label.config(text="...") — изменить текст метки

command=функция — что делать при клике (без скобок!)

📐 Параметры pack()

Метод pack() размещает виджеты в окне. У него есть полезные параметры для управления расположением.

side — с какой стороны

# По умолчанию — сверху (side="top") label1.pack() # Можно указать сторону label2.pack(side="left") # слева label3.pack(side="right") # справа label4.pack(side="bottom") # снизу

fill — заполнение пространства

# Растянуть по горизонтали label.pack(fill="x") # Растянуть по вертикали label.pack(fill="y") # Растянуть в обе стороны label.pack(fill="both")

expand — занимать всё свободное место

# Виджет займёт всё доступное пространство label.pack(expand=True)

anchor — выравнивание

# Выравнивание по сторонам света label.pack(anchor="n") # север (сверху) label.pack(anchor="s") # юг (снизу) label.pack(anchor="w") # запад (слева) label.pack(anchor="e") # восток (справа) label.pack(anchor="center") # по центру
💡 Комбинируем параметры:

label.pack(side="left", padx=10, pady=5, fill="x", expand=True)

📍 place() и grid()

Кроме pack(), есть ещё два способа размещения виджетов: place() (точные координаты) и grid() (сетка).

place() — точные координаты

Размещает виджет по конкретным координатам x и y:

# Абсолютные координаты (в пикселях) label.place(x=50, y=100) # Относительные координаты (от 0.0 до 1.0) label.place(relx=0.5, rely=0.5) # центр окна # С размерами button.place(x=10, y=10, width=100, height=30)
️ Когда использовать place():

✅ Когда нужно точное позиционирование

️ Неудобно при изменении размера окна

⚠️ Сложно поддерживать при добавлении новых виджетов

grid() — размещение по сетке

grid() размещает виджеты в таблице (строки и столбцы). Это самый удобный способ для сложных интерфейсов!

# Размещаем в строке 0, столбце 0 label1.grid(row=0, column=0) # Строка 0, столбец 1 label2.grid(row=0, column=1) # Строка 1, столбец 0 entry.grid(row=1, column=0) # Строка 1, столбец 1 button.grid(row=1, column=1)
📊 Как работает grid:

Представь таблицу Excel:

row — номер строки (с 0)

column — номер столбца (с 0)

Виджеты автоматически выравниваются!

Параметры grid

# Отступы label.grid(row=0, column=0, padx=10, pady=5) # Растянуть на несколько столбцов button.grid(row=2, column=0, columnspan=2) # Растянуть на несколько строк text.grid(row=0, rowspan=3) # Выравнивание внутри ячейки label.grid(row=0, column=0, sticky="w") # прижать к западу (левому краю)
💡 sticky — как приклеить виджет:

"n" — север (сверху), "s" — юг (снизу)

"w" — запад (слева), "e" — восток (справа)

"nsew" — растянуть во все стороны

💬 messagebox и Text

tkinter имеет много полезных виджетов. Начнём с всплывающих окон и многострочного текста.

messagebox — всплывающие окна

messagebox — это модуль для показа небольших диалоговых окон. Его нужно импортировать отдельно:

from tkinter import messagebox # Информационное окно (только кнопка OK) messagebox.showinfo("Заголовок", "Текст сообщения") # Предупреждение (жёлтый значок) messagebox.showwarning("Внимание", "Что-то не так!") # Ошибка (красный значок) messagebox.showerror("Ошибка", "Произошла ошибка!")

Окна с вопросом

Некоторые messagebox возвращают значение — True или False, в зависимости от того, что нажал пользователь:

# Да / Нет — возвращает True или False result = messagebox.askyesno("Вопрос", "Ты уверен?") if result: print("Пользователь нажал Да") else: print("Пользователь нажал Нет") # OK / Отмена — возвращает True или False ok = messagebox.askokcancel("Подтверждение", "Продолжить?") # Повторить / Отмена — возвращает строку "retry" или "cancel" choice = messagebox.askretrycancel("Ошибка", "Заново?")
💡 Практический пример — подтверждение удаления:
def delete(): answer = messagebox.askyesno("Удаление", "Вы уверены?") if answer: print("Удалено!") else: print("Отменено") btn = tk.Button(window, text="Удалить", command=delete) btn.pack()

Text — многострочное поле ввода

В отличие от Entry (одна строка), Text позволяет вводить много строк текста, как в блокноте.

# Большое поле для текста text = tk.Text(window, width=40, height=10) text.pack() # Вставить текст text.insert("1.0", "Привет!") # Получить весь текст content = text.get("1.0", "end")
🔑 Индексы в Text — формат "строка.символ":

В Text каждый символ имеет адрес в формате "строка.символ":

"1.0" — строка 1, символ 0 (самое начало текста)

"2.5" — строка 2, символ 5 (шестой символ второй строки)

"3.0" — начало третьей строки

"end" — самый конец текста (после последнего символа)

"end-1c" — конец минус 1 символ (убирает лишний перенос строки)

️ Важно:

Нумерация строк начинается с 1 (не с 0!) — это исторически сложилось в tkinter

Нумерация символов начинается с 0 — как в списках Python

Индексы всегда пишутся в кавычках, потому что это строки: "1.0", а не 1.0

💡 Примеры использования индексов:

text.insert("1.0", "Привет") — вставить "Привет" в самое начало

text.insert("end", "\nНовая строка") — добавить текст в конец

text.delete("1.0", "end") — очистить весь текст

text.get("1.0", "end-1c") — получить весь текст без лишнего переноса

☑️ Radiobutton, Checkbutton, Listbox

Эти виджеты работают не как обычные — им нужны специальные переменные tkinter, чтобы "запоминать" своё состояние.

Специальные переменные tkinter

Обычные переменные Python (name = "Алиса") не подходят для виджетов. tkinter использует свои переменные, которые умеют уведомлять виджеты об изменениях:

text_var = tk.StringVar() # для текста num_var = tk.IntVar() # для целых чисел float_var = tk.DoubleVar() # для дробных чисел bool_var = tk.BooleanVar() # для True/False
🔑 Два главных метода:

var.get() — получить текущее значение переменной

var.set("новое") — установить новое значение

Когда значение меняется через set(), все виджеты, связанные с этой переменной, автоматически обновляются!

Radiobutton — выбор одного из нескольких

Несколько Radiobutton объединяются одной переменной. Выбран может быть только один:

color_var = tk.StringVar() # одна переменная на все кнопки color_var.set("red") # значение по умолчанию # Все три кнопки связаны с color_var tk.Radiobutton(window, text="Красный", variable=color_var, value="red").pack() tk.Radiobutton(window, text="Синий", variable=color_var, value="blue").pack() tk.Radiobutton(window, text="Зелёный", variable=color_var, value="green").pack() # Узнать, что выбрано: print(color_var.get()) # "red", "blue" или "green"
💡 Как это работает:

Все Radiobutton имеют одинаковый параметр variable=color_var

Но разный параметр value — это то, что запишется в переменную при выборе

Когда пользователь кликает на кнопку, в color_var автоматически записывается её value

Checkbutton — флажок (да/нет)

Checkbutton может быть включён или выключен. Использует BooleanVar:

agree_var = tk.BooleanVar() # True или False check = tk.Checkbutton( window, text="Я согласен с правилами", variable=agree_var ) check.pack() # Проверить состояние: if agree_var.get(): print("Галочка стоит!") else: print("Галочка не стоит")
⚙️ onvalue и offvalue:

По умолчанию Checkbutton записывает True/False. Но можно задать свои значения:

mode_var = tk.StringVar() tk.Checkbutton(window, text="Ночь", variable=mode_var, onvalue="night", # когда включён offvalue="day").pack() # когда выключен

Listbox — список элементов

Listbox показывает список, из которого пользователь может выбрать один или несколько элементов:

listbox = tk.Listbox(window) listbox.pack() # Добавить элементы listbox.insert("end", "Яблоко") listbox.insert("end", "Банан") listbox.insert("end", "Апельсин") # Получить выбранный элемент selected = listbox.get(listbox.curselection()) # Удалить выбранный listbox.delete(listbox.curselection())
💡 Полезные методы Listbox:

insert("end", "текст") — добавить в конец списка

insert(0, "текст") — добавить в начало

get(i) — получить элемент по индексу

curselection() — получить индекс выбранного элемента

delete(i) — удалить элемент по индексу

size() — количество элементов в списке

Полный пример: анкета

Соберём всё вместе — анкету с Radiobutton, Checkbutton и кнопкой:

import tkinter as tk from tkinter import messagebox window = tk.Tk() window.title("Анкета") gender_var = tk.StringVar() agree_var = tk.BooleanVar() tk.Label(window, text="Выбери пол:").pack() tk.Radiobutton(window, text="М", variable=gender_var, value="М").pack() tk.Radiobutton(window, text="Ж", variable=gender_var, value="Ж").pack() tk.Checkbutton(window, text="Согласен", variable=agree_var).pack() def submit(): gender = gender_var.get() agree = agree_var.get() if not gender: messagebox.showwarning("Ошибка", "Выбери пол!") elif not agree: messagebox.showwarning("Ошибка", "Нужно согласие!") else: messagebox.showinfo("Готово", f"Пол: {gender}") tk.Button(window, text="Отправить", command=submit).pack() window.mainloop()
