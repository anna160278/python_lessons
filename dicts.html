📦 Что такое кортежи?

Кортеж (tuple) — это неизменяемый упорядоченный набор элементов. Похож на список, но после создания его нельзя изменить.

# Создание кортежей point = (3, 4) colors = ("красный", "зелёный", "синий") single = (42,) # кортеж из 1 элемента (запятая обязательна!) empty = () # пустой кортеж # Создание через функцию tuple() from_list = tuple([1, 2, 3]) from_str = tuple("abc") print(from_list) # (1, 2, 3) print(from_str) # ('a', 'b', 'c')
💡 Зачем нужны кортежи:

✅ Быстрее списков — Python оптимизирует их

✅ Защищают данные от случайного изменения

✅ Удобны для возврата нескольких значений из функции

Работа с кортежами

Кортежи поддерживают те же операции, что и списки: индексацию, срезы и перебор циклом.

Доступ к элементам

t = (10, 20, 30, 40, 50) # Индексация print(t[0]) # 10 (первый элемент) print(t[-1]) # 50 (последний элемент) # Срезы print(t[1:4]) # (20, 30, 40) print(t[::2]) # (10, 30, 50) — каждый второй print(t[::-1]) # (50, 40, 30, 20, 10) — в обратном порядке

Перебор циклом for

colors = ("красный", "зелёный", "синий") for color in colors: print(color) # красный # зелёный # синий # С индексами for i in range(len(colors)): print(i, colors[i]) # 0 красный # 1 зелёный # 2 синий

Распаковка кортежей

# Распаковка в переменные point = (3, 4) x, y = point print(x, y) # 3 4 # Обмен значений a, b = 1, 2 a, b = b, a print(a, b) # 2 1 # Упаковка — создание кортежа без скобок coords = 10, 20, 30 print(coords) # (10, 20, 30)
💡 Полезные приёмы:

t[i] — доступ по индексу

t[a:b] — срез кортежа

x, y = point — распаковка в переменные

a, b = b, a — обмен значений без временной переменной

🔗 Операции с кортежами

С кортежами можно выполнять конкатенацию, повторение и использовать методы count() и index().

a = (1, 2) b = (3, 4) # Конкатенация print(a + b) # (1, 2, 3, 4) # Повторение print(a * 3) # (1, 2, 1, 2, 1, 2) # count и index t = (1, 2, 2, 3, 2) print(t.count(2)) # 3 print(t.index(3)) # 3 # Проверка вхождения print(2 in t) # True
💡 Кортежи vs Списки:

(1, 2, 3) — кортеж, нельзя изменять

[1, 2, 3] — список, можно изменять

Синтаксис похож, но круглые скобки вместо квадратных

Что такое словари?

Словарь (dict) — это неупорядоченная коллекция пар ключ:значение. Ключи уникальны, значения могут повторяться.

# Создание словарей student = {"name": "Алиса", "age": 20, "grade": "A"} empty = {} # пустой словарь from_list = dict(name="Боб", age=25) # Получение значения по ключу print(student["name"]) # Алиса print(len(student)) # 3 # Добавление нового ключа student["city"] = "Athens" print(student) # {'name': 'Алиса', 'age': 20, 'grade': 'A', 'city': 'Athens'} # Изменение существующего значения student["age"] = 15 print(student["age"]) # 15
⚠️ Правила ключей:

✅ Ключи должны быть неизменяемыми (строки, числа, кортежи)

✅ Ключи уникальны — при дублировании перезаписывается значение

✅ Кортежи можно использовать как ключи: {(0, 0): "начало"}

❌ Списки и словари не могут быть ключами

️ Методы словарей

Словари имеют удобные методы для безопасной работы с данными.

student = {"name": "Алиса", "age": 20} # get — безопасное получение значения # Первый аргумент — ключ, второй — значение по умолчанию # Если ключ не найден, возвращается второй аргумент print(student.get("name")) # Алиса print(student.get("grade", "?")) # ? (ключа нет, вернули "?") print(student.get("grade")) # None (без второго аргумента) # keys, values, items — получение частей словаря print(student.keys()) # dict_keys(['name', 'age']) print(student.values()) # dict_values(['Алиса', 20]) print(student.items()) # dict_items([('name', 'Алиса'), ('age', 20)]) # update — добавление/обновление пар student.update({"grade": "A"}) print(student) # {'name': 'Алиса', 'age': 20, 'grade': 'A'} # Удаление элементов # del — удаляет по ключу (ничего не возвращает) del student["grade"] # pop — удаляет по ключу и возвращает значение age = student.pop("age") print(age) # 20
💡 del vs pop:

del d[key] — просто удаляет, ничего не возвращает

d.pop(key) — удаляет и возвращает значение (удобно, если оно нужно)

🔁 Перебор словарей циклом for

Словари можно перебирать разными способами — по ключам, значениям или парам.

Перебор ключей

student = {"name": "Алиса", "age": 20} for key in student: print(key) # name # age

Перебор значений

for value in student.values(): print(value) # Алиса # 20

Перебор пар ключ-значение

for key, value in student.items(): print(key, "→", value) # name → Алиса # age → 20
💡 Полезные приёмы:

for key in dict: — перебор ключей (по умолчанию)

for value in dict.values(): — перебор значений

for key, value in dict.items(): — перебор пар

💻 Практические паттерны

Рассмотрим полезные приёмы работы со словарями и кортежами.

Счётчик элементов — вариант 1 (через if)

words = ["кот", "пёс", "кот", "кот", "пёс"] counter = {} for word in words: if word in counter: counter[word] += 1 else: counter[word] = 1 print(counter) # {'кот': 3, 'пёс': 2}

Счётчик элементов — вариант 2 (через get)

words = ["кот", "пёс", "кот", "кот", "пёс"] counter = {} for word in words: counter[word] = counter.get(word, 0) + 1 print(counter) # {'кот': 3, 'пёс': 2}
💡 Как работает вариант через get:

counter.get(word, 0) — берёт текущее значение ключа word, а если ключа ещё нет — возвращает 0

Затем прибавляем 1 и записываем обратно в counter[word]

При первом появлении слова: 0 + 1 = 1

При втором: 1 + 1 = 2, и так далее

Использование кортежей как ключей

# Координаты как ключи словаря grid = {} grid[(0, 0)] = "начало" grid[(1, 2)] = "точка" print(grid[(0, 0)]) # начало # Нельзя использовать список как ключ: # grid[[0, 0]] = "ошибка" # TypeError!
