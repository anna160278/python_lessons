Базовая арифметика

Python поддерживает все стандартные математические операции. Результат зависит от типов операндов.

# Сложение и вычитание print(10 + 3) # 13 print(10 - 3) # 7 # Умножение и деление print(10 * 3) # 30 print(10 / 3) # 3.3333... (всегда float!) print(10 / 2) # 5.0 (тоже float!)
💡 Важно:

Оператор / всегда возвращает число с точкой (float), даже если делится без остатка.

➗ Целочисленное деление и остаток

Помимо обычного деления, в Python есть целочисленное деление // и оператор остатка %.

# Целочисленное деление — отбрасывает дробную часть print(10 // 3) # 3 (не 3.333...) print(7 // 2) # 3 print(10 // 5) # 2 # Остаток от деления print(10 % 3) # 1 (10 = 3*3 + 1) print(7 % 2) # 1 (7 = 2*3 + 1) print(10 % 5) # 0 (делится без остатка)
💡 Где это полезно:

n % 2 == 0 — проверка на чётность

n % 10 — последняя цифра числа

n // 10 — число без последней цифры

Возведение в степень

В Python для возведения в степень используется оператор **.

print(2 ** 3) # 8 (2 * 2 * 2) print(5 ** 2) # 25 (5 * 5) print(10 ** 0) # 1 (любое число в степени 0 = 1) print(2 ** 10) # 1024 # Дробная степень — извлечение корня print(9 ** 0.5) # 3.0 (квадратный корень) print(27 ** (1/3)) # 3.0 (кубический корень)
💡 Приоритет операций:

Приоритет выполнения арифметических действий такой же, как в математике: первым выполняется возведение в степень (**), потом умножение (*) и деление (/), и только потом сложение (+) и вычитание (-). Поменять порядок действий можно с помощью скобок.

🔀 Условие if

Условные конструкции позволяют выполнять разный код в зависимости от условий.

age = 18 if age >= 18: print("Совершеннолетний") # Сравнение чисел x = 10 if x > 0: print("Положительное") if x % 2 == 0: print("Чётное")

Операторы сравнения:

5 == 5 # True (равно) 5 != 3 # True (не равно) 5 > 3 # True (больше) 5 < 3 # False (меньше) 5 >= 5 # True (больше или равно) 5 <= 3 # False (меньше или равно)
💡 Правила:

После if ставится двоеточие :, тело выделяется отступом (4 пробела).

🔀 else и elif

else выполняется, если условие if ложно. elif позволяет проверять несколько условий.

score = 75 if score >= 90: print("Отлично") elif score >= 70: print("Хорошо") elif score >= 50: print("Удовлетворительно") else: print("Не сдал")
💡 Как это работает:

Python проверяет условия сверху вниз. Как только найдёт истинное — выполнит его блок и пропустит все остальные.

Логические операторы

Операторы and, or и not позволяют комбинировать условия.

age = 25 money = 500 # and — оба условия истинны if age >= 18 and money >= 100: print("Можно купить") # or — хотя бы одно истинно if age < 12 or age > 65: print("Скидка") # not — инверсия is_banned = False if not is_banned: print("Доступ разрешён")
💡 Таблица истинности:

True and True → True  |  True and False → False

True or False → True  |  False or False → False

not True → False    |  not False → True
