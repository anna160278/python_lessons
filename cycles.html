🔄 Цикл while

Цикл while выполняет код ПОКА условие истинно. Как только условие становится ложным — цикл завершается.

# Простой счётчик i = 1 while i <= 5: print(i, end=" ") i += 1 # Вывод: 1 2 3 4 5

Выход из цикла с помощью break

i = 1 while i <= 10: if i == 5: break print(i, end=" ") i += 1 # Вывод: 1 2 3 4
⚠️ Бесконечные циклы:

while True: — бесконечный цикл. Используйте break для выхода.

🔁 Цикл for и функция range()

Цикл for перебирает элементы последовательности. Чаще всего используется с функцией range().

Цикл с range()

# range(5) генерирует числа 0, 1, 2, 3, 4 # Цикл выполнится 5 раз for i in range(5): print(i, end=" ") # Вывод: 0 1 2 3 4

Разные варианты range()

range(5) # 0, 1, 2, 3, 4 (5 чисел) range(2, 6) # 2, 3, 4, 5 (конец не включён) range(0, 10, 2) # 0, 2, 4, 6, 8 (шаг 2) range(5, 0, -1) # 5, 4, 3, 2, 1 (обратный порядок)
💡 Запомните:

range(n) — цикл выполнится n раз, значения от 0 до n-1

range(a, b) — значения от a до b-1 (b не включается)

range(a, b, step) — значения от a до b-1 с шагом step

⏹️ break и continue

Эти операторы позволяют управлять выполнением циклов.

# break — прерывает цикл полностью for i in range(10): if i == 5: break print(i, end=" ") # Вывод: 0 1 2 3 4
# continue — пропускает текущую итерацию for i in range(5): if i == 2: continue print(i, end=" ") # Вывод: 0 1 3 4 (пропущено 2)
💡 Разница:

break — полностью выходит из цикла

continue — пропускает только текущую итерацию и идёт дальше

1. Что делает break?
Пропускает итерацию
Полностью выходит из цикла

Повторяет итерацию
