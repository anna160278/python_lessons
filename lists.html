✅ Что такое списки?

Список (list) — это упорядоченная коллекция элементов. В отличие от строк, списки изменяемы — можно добавлять, удалять и менять элементы.

# Создание списков numbers = [1, 2, 3, 4, 5] fruits = ["яблоко", "банан", "вишня"] mixed = [1, "два", 3.0, True] empty = [] # пустой список print(numbers) # [1, 2, 3, 4, 5] print(fruits) # ['яблоко', 'банан', 'вишня'] print(len(fruits)) # 3
💡 Особенности списков:

✅ Могут содержать элементы разных типов

✅ Элементы упорядочены (имеют индексы)

✅ Можно изменять после создания

✅ Могут содержать дубликаты

📍 Индексация и срезы

Как и строки, списки поддерживают индексацию и срезы. Индексация начинается с 0.

colors = ["красный", "зелёный", "синий", "жёлтый"] # 0 1 2 3 # -4 -3 -2 -1 print(colors[0]) # красный (первый) print(colors[-1]) # жёлтый (последний) print(colors[1:3]) # ['зелёный', 'синий'] print(colors[::2]) # ['красный', 'синий']

Изменение элементов

numbers = [1, 2, 3, 4] numbers[0] = 10 print(numbers) # [10, 2, 3, 4] numbers[1:3] = [20, 30] print(numbers) # [10, 20, 30, 4]

➕ Добавление элементов

Списки имеют методы для добавления элементов: append(), extend(), insert().

nums = [1, 2, 3] # append — добавляет один элемент в конец nums.append(4) print(nums) # [1, 2, 3, 4] # extend — добавляет несколько элементов nums.extend([5, 6]) print(nums) # [1, 2, 3, 4, 5, 6] # insert — вставляет элемент по индексу nums.insert(0, 0) print(nums) # [0, 1, 2, 3, 4, 5, 6]
💡 Разница между append и extend:

append([7, 8]) добавит список как один элемент: [..., [7, 8]]

extend([7, 8]) добавит элементы по отдельности: [..., 7, 8]

🗑️ Удаление элементов

Методы remove(), pop() и clear() позволяют удалять элементы из списка.

nums = [1, 2, 3, 4, 5] # remove — удаляет по значению (первое вхождение) nums.remove(3) print(nums) # [1, 2, 4, 5] # pop — удаляет по индексу и возвращает элемент x = nums.pop(0) print(x) # 1 print(nums) # [2, 4, 5] # pop() без аргумента — удаляет последний nums.pop() print(nums) # [2, 4] # clear — очищает весь список nums.clear() print(nums) # []
⚠️ Важно:

remove() вызывает ошибку, если элемент не найден. Используйте in для проверки.

Перебор списков циклом for

Цикл for позволяет перебирать элементы списка по одному. Это один из самых распространённых способов работы со списками.

Простой перебор

fruits = ["яблоко", "банан", "вишня"] for fruit in fruits: print(fruit) # Вывод: # яблоко # банан # вишня

Перебор с индексами

colors = ["красный", "зелёный", "синий"] for i in range(len(colors)): print(i, colors[i]) # Вывод: # 0 красный # 1 зелёный # 2 синий

Перебор с enumerate()

colors = ["красный", "зелёный", "синий"] for i, color in enumerate(colors): print(i, color) # Вывод: # 0 красный # 1 зелёный # 2 синий

Перебор с условием

numbers = [1, 2, 3, 4, 5, 6] for num in numbers: if num % 2 == 0: print(num, end=" ") # Вывод: 2 4 6
💡 Полезные приёмы:

for item in list: — простой перебор элементов

for i in range(len(list)): — перебор с индексами

for i, item in enumerate(list): — перебор с индексами и элементами

🔧 Полезные методы

Списки имеют множество полезных методов для работы с данными.

nums = [3, 1, 4, 1, 5, 9, 2, 6] # index — найти индекс элемента print(nums.index(4)) # 2 # count — посчитать вхождения print(nums.count(1)) # 2 # sort — сортировка (изменяет список) nums.sort() print(nums) # [1, 1, 2, 3, 4, 5, 6, 9] # reverse — переворот списка nums.reverse() print(nums) # [9, 6, 5, 4, 3, 2, 1, 1] # copy — создать копию nums2 = nums.copy()
💡 sort() vs sorted():

list.sort() — изменяет список на месте

sorted(list) — возвращает новый отсортированный список

🔗 Операции со списками
