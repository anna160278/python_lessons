✅ Что такое множества?

Множество (set) — это неупорядоченная коллекция уникальных элементов. Дубликаты автоматически удаляются.

# Создание множеств numbers = {1, 2, 3, 4, 5} fruits = {"яблоко", "банан", "вишня"} empty = set() # пустое множество (не {}!) # Из списка — удаляются дубликаты unique = set([1, 2, 2, 3, 3, 3]) print(unique) # {1, 2, 3} print(len(numbers)) # 5
️ Особенности множеств:

✅ Элементы уникальны — дубликаты удаляются автоматически

✅ Неупорядочены — элементы не имеют индексов

✅ Элементы должны быть неизменяемыми (числа, строки, кортежи)

➕ Добавление и удаление элементов

Множества изменяемы — можно добавлять и удалять элементы.

s = {1, 2, 3} # add — добавить один элемент s.add(4) print(s) # {1, 2, 3, 4} # update — добавить несколько элементов s.update([5, 6, 7]) print(s) # {1, 2, 3, 4, 5, 6, 7} # remove — удалить элемент (ошибка, если нет) s.remove(3) print(s) # {1, 2, 4, 5, 6, 7} # discard — удалить элемент (без ошибки) s.discard(10) # ничего не произойдёт # pop — удалить случайный элемент x = s.pop() print(x) # какой-то элемент из множества # clear — очистить множество полностью s.clear() print(s) # set()
💡 remove vs discard:

remove(x) — удаляет x, вызывает ошибку если x нет в множестве

discard(x) — удаляет x, ничего не делает если x нет

🔗 Операции над множествами

Множества поддерживают математические операции: объединение, пересечение, разность.

a = {1, 2, 3, 4} b = {3, 4, 5, 6} # Объединение — все элементы из обоих множеств print(a | b) # {1, 2, 3, 4, 5, 6} print(a.union(b)) # {1, 2, 3, 4, 5, 6} # Пересечение — только общие # (пересекающиеся) элементы print(a & b) # {3, 4} print(a.intersection(b)) # {3, 4} # Разность — элементы из a, которых нет в b print(a - b) # {1, 2} print(a.difference(b)) # {1, 2} # Симметрическая разность - # это все элементы обоих множеств, кроме пересекающихся print(a ^ b) # {1, 2, 5, 6} print(a.symmetric_difference(b)) # {1, 2, 5, 6}
💡 Круги Эйлера (диаграммы Венна):
A | B (Объединение)
A & B (Пересечение)
A - B (Разность)
A ^ B (Симм. разность)

🔍 Проверка вхождения и подмножеств

Множества удобны для быстрой проверки наличия элемента и отношений между множествами.

a = {1, 2, 3, 4, 5} b = {2, 3} c = {6, 7} # Проверка вхождения print(3 in a) # True print(6 in a) # False # Подмножество (все элементы b есть в a) print(b.issubset(a)) # True print(c.issubset(a)) # False # Надмножество (a содержит все элементы b) print(a.issuperset(b)) # True # Непересекающиеся множества print(a.isdisjoint(c)) # True (нет общих элементов) print(a.isdisjoint(b)) # False (есть общие)

a является подмножеством b
a и b не имеют общих элементов
a и b равны
a является надмножеством b

💡 Практические примеры

Множества часто используются для удаления дубликатов и проверки уникальности.

Удаление дубликатов из списка

numbers = [1, 2, 2, 3, 3, 3, 4, 4, 5] unique = list(set(numbers)) print(unique) # [1, 2, 3, 4, 5] (порядок может отличаться)

Проверка уникальности

lst1 = [1, 2, 3] print(len(lst1) == len(set(lst1))) # True (длина совпадает) lst2 = [1, 2, 2, 3] print(len(lst2) == len(set(lst2))) # False (есть дубликаты)

Поиск общих элементов

group1 = {"Алиса", "Боб", "Чарли"} group2 = {"Боб", "Дейв", "Ева"} common = group1 & group2 print(common) # {'Боб'}
