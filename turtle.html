✅ Подключение библиотеки

Модуль turtle входит в стандартную библиотеку Python — его не нужно устанавливать отдельно. Просто импортируйте его в начале программы.

Три способа импорта

# Способ 1: импорт всего модуля import turtle turtle.forward(100) turtle.right(90) # Способ 2: импорт с коротким псевдонимом import turtle as t t.forward(100) t.right(90) # Способ 3: импорт всех функций напрямую from turtle import * forward(100) right(90)
💡 Какой способ выбрать:

✅ from turtle import * — самый удобный для обучения, короткие команды без префикса

✅ import turtle as t — золотая середина: короткий префикс t. и доступ ко всем функциям

✅ import turtle — хорош для больших проектов, сразу видно откуда функция

⚠️ Избегайте from turtle import * в серьёзных проектах — может конфликтовать с другими библиотеками

️ Не используйте from turtle import forward, right — вы получите только эти две функции, остальные будут недоступны

Настройка окна и запуск

from turtle import * # Настройка окна setup(600, 400) # ширина 600, высота 400 bgcolor("lightblue") # цвет фона title("Мой рисунок") # заголовок окна # Рисуем квадрат for i in range(4): forward(100) right(90) # Оставляем окно открытым mainloop()

Движение и повороты

Черепашка начинает в центре экрана и смотрит вправо (на восток). Она может двигаться вперёд/назад и поворачиваться.

forward(100) # пройти вперёд 100 пикселей backward(50) # пройти назад 50 пикселей right(90) # повернуть направо на 90° left(45) # повернуть налево на 45°

Абсолютный поворот: setheading()

В отличие от left() и right(), которые поворачивают относительно текущего направления, команда setheading() задаёт абсолютное направление. Угол указывается в градусах:

setheading(0) # смотреть на восток (вправо) → setheading(90) # смотреть на север (вверх) ↑ setheading(180) # смотреть на запад (влево) ← setheading(270) # смотреть на юг (вниз) ↓ setheading(-90) # тоже самое, что 270 (вниз) ↓ # Разница: right(90) # повернуть на 90° от текущего направления setheading(90) # всегда смотреть вверх, # независимо от текущего направления
💡 Как работает отсчёт углов:

✅ Углы отсчитываются против часовой стрелки от направления "вправо" (0°)

✅ setheading(90) — поворот на 90° против часовой = вверх

✅ setheading(-90) — поворот на 90° по часовой = вниз (то же, что 270°)

✅ Отрицательные углы — это поворот по часовой стрелке

✅ setheading(360) = setheading(0) — полный оборот

🔷 Рисование фигур

С помощью циклов можно рисовать правильные многоугольники. Также есть специальные команды для кругов и точек.

Квадрат и треугольник

# Квадрат for i in range(4): forward(100) right(90) # Треугольник for i in range(3): forward(100) right(120)
💡 Формула угла поворота:

Для правильного n-угольника угол поворота = 360 / n

Квадрат (4 стороны): 360 / 4 = 90°

Треугольник (3 стороны): 360 / 3 = 120°

Шестиугольник (6 сторон): 360 / 6 = 60°

Круг и точка

# Круг — рисует окружность заданного радиуса circle(50) # круг радиусом 50 пикселей circle(30) # круг радиусом 30 пикселей # Точка — рисует заполненный кружок заданного размера dot(20) # точка диаметром 20 пикселей dot(10, "red") # красная точка диаметром 10
Разница между circle() и dot():

circle(r) — рисует окружность (контур), черепашка движется по кругу

dot(size) — рисует заполненную точку, черепашка остаётся на месте

dot() удобен для точек на графике или создания узоров

🎨 Цвета и заполнение

Можно менять цвет пера, цвет фона и заполнять фигуры цветом.

Именованные цвета

color("red") # красный color("blue") # синий color("green") # зелёный color("yellow") # жёлтый color("purple") # фиолетовый color("orange") # оранжевый bgcolor("lightblue") # цвет фона окна

Цвета в формате RGB

# ⚠️ Важно! Без этой строки RGB цвета не работают! # По умолчанию turtle использует режим 0.0–1.0 t.Screen().colormode(255) # RGB — красный, зелёный, синий (от 0 до 255) color(255, 0, 0) # красный color(0, 255, 0) # зелёный color(0, 0, 255) # синий color(255, 255, 0) # жёлтый color(128, 0, 128) # фиолетовый # Можно использовать кортеж color((255, 128, 0)) # оранжевый
⚠️ Почему нужна colormode(255):

По умолчанию turtle работает в режиме colormode(1.0), где цвета задаются дробными числами от 0.0 до 1.0

Screen().colormode(255) переключает режим на целые числа от 0 до 255 — как в веб-дизайне

Если используете from turtle import *, пишите просто Screen().colormode(255)

Без этой строки color(255, 0, 0) вызовет ошибку TurtleGraphicsError!

Заполнение фигур

color("red") begin_fill() # начать запоминать контур for i in range(4): forward(100) right(90) end_fill() # заполнить фигуру текущим цветом
💡 Разница между color(), pencolor() и fillcolor():

color("red") — задаёт и цвет пера, и цвет заполнения

pencolor("blue") — только цвет линии (перо остаётся синим, заполнение не меняется)

fillcolor("yellow") — только цвет заполнения (перо не меняется)

Пример: pencolor("black") + fillcolor("red") → чёрный контур, красная середина

💡 Популярные цвета:

Именованные: "red", "blue", "green", "yellow", "purple", "orange", "pink", "brown"

RGB: любой цвет можно задать тремя числами от 0 до 255

HEX: color("#FF5733") — тоже работает

Управление черепашкой

Можно менять внешний вид черепашки, скорость, оставлять отпечатки и писать текст.

Форма черепашки

shape("turtle") # черепашка (по умолчанию) shape("arrow") # стрелка shape("circle") # круг shape("square") # квадрат shape("triangle") # треугольник shape("classic") # классическая стрелка

Скорость

speed(1) # медленно speed(5) # нормально speed(10) # быстро speed(0) # мгновенно (без анимации)

Отпечатки и видимость

stamp() # оставить отпечаток черепашки hideturtle() # скрыть черепашку showturtle() # показать черепашку # Написать текст write("Привет!", font=("Arial", 16, "bold"))
