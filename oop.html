📦 Что такое классы и объекты?

Представь, что ты делаешь игру с машинами . У каждой машины есть цвет, марка и скорость. Если у тебя 100 машин, писать код для каждой отдельно — долго и скучно!

Вместо этого мы создаём класс — это как чертёж машины. Один раз нарисовали чертёж — и можем построить по нему сколько угодно машин!

Аналогия с машинами:

Класс Car — это чертёж машины (общий план: у каждой будет цвет, марка, скорость)

Объект my_car — это конкретная машина, построенная по чертежу (красная Toyota, едет 120 км/ч)

По одному чертежу можно построить много разных машин: красную, синюю, зелёную!

# Создаём класс (чертёж машины) class Car: pass # пока пустой чертёж # Строим конкретные машины по чертежу car1 = Car() # первая машина car2 = Car() # вторая машина print(type(car1)) # <class '__main__.Car'>

Атрибуты класса — общие свойства всех машин

У всех машин есть общие свойства: у каждой 4 колеса и 1 двигатель. Такие свойства можно задать прямо в классе — они будут одинаковыми для всех объектов.

class Car: wheels = 4 # у всех машин 4 колеса engine = 1 # у всех машин 1 двигатель # Создаём разные машины car1 = Car() car2 = Car() # Обращаемся к атрибутам через точку print(car1.wheels) # 4 print(car2.wheels) # 4 (тоже 4!) print(car1.engine) # 1 # Можно обратиться и через имя класса print(Car.wheels) # 4
🔑 Запомни:

class — создаёт новый класс.

Имя класса пишется с большой буквы: Car, Robot, Player

() после имени класса — строит объект (как "запустить конвейер")

объект.атрибут — обращаемся к свойству через точку

Атрибуты класса одинаковы для всех объектов, пока мы их не изменим

⚙️ Атрибуты и конструктор __init__

У каждого объекта есть свойства (атрибуты) и действия (методы). Если ты уже знаешь, что такое переменные и функции — считай, что половину ООП ты уже понял!

💡 Простая аналогия:

Атрибут — это как переменная, только "принадлежащая" объекту

Метод — это как функция, только "живущая" внутри класса

Атрибуты хранят данные (цвет, скорость), методы — выполняют действия (ехать, сигналить)

Задаём атрибуты напрямую

Самый простой способ — создать объект и сразу задать ему свойства через точку:

class Car: pass # пустой класс # Создаём машину car1 = Car() car1.color = "красный" # атрибут (как переменная) car1.brand = "Toyota" car1.speed = 120 print(car1.color) # красный print(car1.brand) # Toyota
⚠️ Проблема:

Если нужно создать 10 машин, придётся для каждой писать 3 строки:

car1.color = "красный", car1.brand = "Toyota", car1.speed = 120

car2.color = "синий", car2.brand = "BMW", car2.speed = 150

...и так 10 раз! Это много повторяющегося кода.

Решение: конструктор __init__

Чтобы не писать одно и то же много раз, используем конструктор — специальный метод __init__, который автоматически запускается при создании объекта.

class Car: def __init__(self, color, brand, speed): self.color = color # сохраняем цвет self.brand = brand # сохраняем марку self.speed = speed # сохраняем скорость # Теперь создаём машины в одну строку! car1 = Car("красный", "Toyota", 120) car2 = Car("синий", "BMW", 150) print(car1.color) # красный print(car2.brand) # BMW
🔑 Как работает __init__:

1️⃣ Когда пишем car1 = Car("красный", "Toyota", 120), Python автоматически вызывает __init__

2️ Аргументы "красный", "Toyota", 120 попадают в параметры color, brand, speed

3️⃣ self.color = color означает: "сохрани значение color в атрибут color этого объекта"

4️⃣ self — это ссылка на конкретный объект (на car1 или car2)

💡 Запомни:

Атрибут = переменная внутри объекта (self.color)

__init__ — конструктор, запускается автоматически при создании объекта

self — ссылка на текущий объект, всегда первый параметр

🎭 Методы и много объектов

Кроме свойств, у объектов есть действия (методы). Это функции внутри класса, которые могут использовать атрибуты через self.

Методы — действия объекта

class Car: def __init__(self, color, brand): self.color = color self.brand = brand def honk(self): # метод (функция внутри класса) print(f"{self.brand} говорит: Би-бип!") def info(self): # метод (функция внутри класса) print(f"{self.color} {self.brand}") car1 = Car("красный", "Toyota") car1.honk() # Toyota говорит: Би-бип! car1.info() # красный Toyota

🔒 Инкапсуляция (защита данных)

Иногда нужно защитить данные объекта от случайного изменения. Например, баланс в банке нельзя менять напрямую — только через специальные методы.

class BankAccount: def __init__(self, balance): self.__balance = balance # приватный атрибут (2 подчёркивания) def deposit(self, amount): if amount > 0: self.__balance += amount print(f"Внесено {amount}") def get_balance(self): return self.__balance acc = BankAccount(1000) acc.deposit(500) # Внесено 500 print(acc.get_balance()) # 1500 # print(acc.__balance) # ❌ Ошибка! Нельзя напрямую
🔑 Правила инкапсуляции:

🔒 Приватный атрибут — имя начинается с двух подчёркиваний: __balance

✅ Геттер — метод для чтения (get_balance())

✅ Сеттер — метод для изменения с проверкой (deposit())

⚠️ Прямой доступ acc.__balance вызовет ошибку — это защита!

🧬 Наследование

Наследование — это когда один класс получает все свойства и методы другого класса. Как в жизни: ребёнок наследует черты родителей.

💡 Аналогия:

👤 Родитель: класс Person (у всех людей есть имя и возраст)

🎓 Ребёнок: класс Student (наследует всё от Person, но добавляет класс/школу)

👨‍ Ребёнок: класс Teacher (наследует всё от Person, но добавляет предмет)

Родительский класс Person

Сначала создадим общий класс для всех людей:

class Person: def __init__(self, name, age): self.name = name self.age = age def info(self): print(f"{self.name}, {self.age} лет") person = Person("Иван", 35) person.info() # Иван, 35 лет

Дочерний класс Student

Теперь создадим класс ученика. Он наследует всё от Person, но добавляет своё поле grade (класс):

class Student(Person): def __init__(self, name, age, grade): super().__init__(name, age) # вызываем конструктор # родительского класса Person self.grade = grade # добавляем своё поле def study(self): print(f"{self.name} учится в {self.grade} классе") student = Student("Алиса", 12, "6А") student.info() # Алиса, 12 лет (метод от родителя!) student.study() # Алиса учится в 6А классе (свой метод)
🔑 Как это работает:

1️ class Student(Person) — Student наследует всё от Person

2️⃣ super().__init__(name, age) — вызываем конструктор родителя, чтобы создать поля name и age

3️⃣ self.grade = grade — добавляем новое поле, которого нет у родителя

4️ student.info() — работает, хотя мы его не писали в Student! Он унаследован от Person

Переопределение метода

Дочерний класс может переопределить метод родителя — написать свою версию с тем же именем:

class Teacher(Person): def __init__(self, name, age, subject): super().__init__(name, age) self.subject = subject def info(self): # переопределяем метод родителя! print(f"{self.name}, учитель {self.subject}") teacher = Teacher("Мария Ивановна", 45, "математики") teacher.info() # Мария Ивановна, учитель математики # (а не "Мария Ивановна, 45 лет" как у Person!)

class Child(Parent) — Child наследует всё от Parent

super().__init__(...) — вызов конструктора родителя

Дочерний класс может переопределить метод родителя (как info() у Teacher)

Если метод не переопределён — используется родительский (как info() у Student)

Полиморфизм

Полиморфизм — "много форм". Один и тот же метод работает по-разному для разных объектов. Как в жизни: команда "Голос!" — собака лает, кошка мяукает, корова мычит.

Базовый класс Animal и его наследники

Создадим общий класс для всех животных, а потом сделаем разных наследников:

class Animal: def __init__(self, name): self.name = name def voice(self): return "..." # по умолчанию — тишина class Cat(Animal): def voice(self): return "Мяу" class Dog(Animal): def voice(self): return "Гав" class Cow(Animal): def voice(self): return "Му"

Один интерфейс — разное поведение

Теперь самое интересное: мы можем работать со всеми животными одинаково, не зная, кто именно перед нами:

# Создаём разных животных animals = [Cat("Барсик"), Dog("Шарик"), Cow("Бурёнка")] # Вызываем один и тот же метод — но каждый отвечает по-своему! for animal in animals: print(f"{animal.name} говорит: {animal.voice()}") # Барсик говорит: Мяу # Шарик говорит: Гав # Бурёнка говорит: Му
💡 В чём магия?

Цикл for animal in animals не знает, кто перед ним — кот, собака или корова

Он просто вызывает animal.voice() — и каждый объект отвечает по-своему

Это и есть полиморфизм: один вызов — много форм

Магические методы: __str__, __add__ и __eq__

Python позволяет переопределять даже операторы! Давай сделаем класс Money — кошелёк с деньгами:

class Money: def __init__(self, amount): self.amount = amount def __str__(self): return f"{self.amount} руб." def __add__(self, other): return Money(self.amount + other.amount) def __eq__(self, other): return self.amount == other.amount wallet1 = Money(500) wallet2 = Money(300) print(wallet1) # 500 руб. — работает __str__ print(wallet1 + wallet2) # 800 руб. — работает __add__ print(wallet1 == wallet2) # False — работает __eq__
💡 Популярные магические методы:

__str__ — как объект выглядит при print()

__add__ — как работает оператор + (сложение двух кошельков)

__eq__ — как работает оператор == (сравнение кошельков)

__len__ — как работает len(obj)
