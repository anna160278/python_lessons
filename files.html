📖 Чтение текстовых файлов

Чтобы прочитать файл, нужно его открыть, прочитать содержимое и закрыть.

Функция open() и метод read()

# 1. Открываем файл для чтения (режим 'r' — read) f = open("note.txt", "r") # 2. Читаем всё содержимое файла в одну строку content = f.read() print(content) # 3. Обязательно закрываем файл, чтобы освободить память! f.close()
🔑 Что здесь происходит:

open("note.txt", "r") — открываем файл note.txt в режиме чтения

f — это переменная, через которую мы "общаемся" с файлом

f.read() — читает всё содержимое файла в одну большую строку

f.close() — закрывает файл (освобождает ресурсы компьютера)

Режимы открытия файла

# "r" — read (чтение). Файл должен существовать. f = open("note.txt", "r") # "w" — write (запись). Создаёт новый файл или стирает старый. f = open("note.txt", "w") # "a" — append (дописка). Добавляет текст в конец файла. f = open("note.txt", "a")

🔤 Кодировки, readlines() и указатель файла

Кодировка и русские буквы

Попробуй открыть файл с русским текстом — и на Windows могут появиться "кракозябры" вместо букв! Почему?

# ❌ Без указания кодировки на Windows - непонятные символы f = open("note.txt", "r") print(f.read()) # ! (кракозябры) f.close() # ✅ Правильно — указываем кодировку явно f = open("note.txt", "r", encoding="utf-8") print(f.read()) # Привет, мир! f.close()
🔑 Почему так происходит:

На Windows по умолчанию используется кодировка cp1251, а на Mac/Linux — utf-8

utf-8 — универсальная кодировка, понимает все языки мира

Чтобы программа работала одинаково на всех компьютерах, всегда указывай encoding="utf-8"

read() vs readlines()

Есть два способа прочитать файл — они возвращают разные результаты:

# Файл scores.txt содержит три строки: # 100 # 250 # 180 # read() — возвращает ОДНУ большую строку f = open("scores.txt", "r", encoding="utf-8") all_text = f.read() print(all_text) # 100 # 250 # 180 f.close() # readlines() — возвращает СПИСОК строк f = open("scores.txt", "r", encoding="utf-8") lines = f.readlines() print(lines) # ['100\n', '250\n', '180\n'] f.close()
⚠️ Важно про readlines():

В конце каждой строки стоит символ \n — это перенос строки

Чтобы его убрать, используем метод strip(): line.strip()

read() удобен, когда нужно всё содержимое сразу

readlines() удобен, когда нужно обработать файл построчно

Указатель файла — важная ловушка!

Когда ты читаешь файл, Python запоминает, где остановился. Это называется "указатель". После первого read() указатель стоит в конце файла, и повторное чтение ничего не даст!

f = open("note.txt", "r", encoding="utf-8") # Первое чтение — всё ок first = f.read() print(first) # "Привет, мир!" # Второе чтение — ПУСТО! Указатель уже в конце файла second = f.read() print(second) # "" (пустая строка!) f.close()
🔑 Как решить проблему указателя:

Способ 1: Сохранить результат в переменную и использовать её

content = f.read() # читаем один раз print(content) # используем переменную print(len(content)) # снова используем переменную

Способ 2: Закрыть и открыть файл заново

Способ 3: Вернуть указатель в начало через f.seek(0)

f.read() # читаем файл f.seek(0) # возвращаем указатель в начало f.read() # читаем снова — теперь работает!

🛡️ Конструкция with

Забывать f.close() — частая ошибка. Если забыть закрыть файл, данные могут не сохраниться, а память компьютера — засориться. Конструкция with автоматически закрывает файл, даже если произошла ошибка.

Синтаксис with

# Чтение файла через with (не нужно писать f.close()) with open("note.txt", "r", encoding="utf-8") as f: content = f.read() print(content) # Файл автоматически закрылся здесь! # Запись через with with open("note.txt", "w", encoding="utf-8") as f: f.write("Новый текст\n") # Файл автоматически закрылся!
💡 Как это работает:

with open(...) as f: — открываем файл и даём ему имя f

Всё, что с отступом внутри with — файл открыт

Как только отступ закончился — файл сам закрылся

Не нужно писать f.close()!

📋 Работа со строками файла

Часто нужно обработать файл построчно: прочитать каждую строку, что-то с ней сделать и сохранить результат.

Цикл по файлу

# Файл scores.txt содержит: # 100 # 250 # 180 with open("scores.txt", "r", encoding="utf-8") as f: for line in f: score = int(line.strip()) # убираем \n и превращаем в число print(f"Счёт: {score}")
💡 Почему for line in f лучше readlines()?

for line in f — читает файл по одной строке, не загружая всё в память

readlines() — загружает весь файл сразу в список (плохо для больших файлов)

Для больших файлов всегда используй for line in f!

Что такое JSON?

JSON (JavaScript Object Notation) — это формат для хранения структурированных данных. Он выглядит как словарь Python, но используется во всех языках программирования.

JSON vs Словарь Python

# Словарь Python: friend = { "name": "Алиса", "age": 12, "hobbies": ["рисование", "игры"] } # Те же данные в JSON (файл friend.json): # { # "name": "Алиса", # "age": 12, # "hobbies": ["рисование", "игры"] # }
⚠️ Важные отличия JSON от Python:

✅ В JSON ключи всегда в двойных кавычках "name", не одинарных 'name'

✅ true/false в JSON пишутся с маленькой буквы (в Python True/False)

✅ null в JSON = None в Python

✅ JSON не поддерживает кортежи () и множества {}

📥 Чтение JSON

Для работы с JSON в Python есть встроенный модуль json. Он умеет превращать JSON в словарь Python и обратно.

json.load() — читаем файл

import json # Файл friend.json: # {"name": "Алиса", "age": 12, "hobbies": ["рисование", "игры"]} with open("friend.json", "r", encoding="utf-8") as f: friend = json.load(f) # JSON → словарь Python print(friend["name"]) # Алиса print(friend["age"]) # 12 print(friend["hobbies"]) # ['рисование', 'игры']

json.loads() — читаем строку

json_string = '{"name": "Борис", "age": 13}' # loads = load string (загружаем из строки) data = json.loads(json_string) print(data["name"]) # Борис

Вложенные данные

# friends.json — список друзей # [ # {"name": "Алиса", "age": 12}, # {"name": "Борис", "age": 13}, # {"name": "Вика", "age": 11} # ] with open("friends.json", "r", encoding="utf-8") as f: friends = json.load(f) # JSON → список словарей for friend in friends: print(f"{friend['name']}, {friend['age']} лет") # Алиса, 12 лет # Борис, 13 лет # Вика, 11 лет

📤 Запись в JSON

json.dump() — записываем в файл

import json friend = { "name": "Алиса", "age": 12, "hobbies": ["рисование", "игры"] } with open("friend.json", "w", encoding="utf-8") as f: json.dump(friend, f, ensure_ascii=False) # словарь Python → JSON в файл

Параметр ensure_ascii=False — сохраняем русские буквы

По умолчанию json.dump() превращает все не-английские символы в \u-коды. Это безопасно, но нечитаемо для человека:

# ❌ Без ensure_ascii=False (по умолчанию): # {"name": "\u0410\u043b\u0438\u0441\u0430", "age": 12} # Это валидный JSON, но человек не может его прочитать! # ✅ С ensure_ascii=False: # {"name": "Алиса", "age": 12} # Читаемо и понятно!
🔑 Когда использовать ensure_ascii=False:

✅ Всегда, когда в данных есть русские (или другие не-английские) буквы

✅ Когда файл будут читать люди (открывать в блокноте)

️ Без этого параметра JSON всё равно будет валидным — просто некрасивым

️ При чтении такого файла через json.load() русские буквы восстановятся автоматически

Параметр indent — красивое форматирование

# Без indent — всё в одну строку: # {"name": "Алиса", "age": 12, "hobbies": ["музыка", "игры"]} # С indent=2 — красиво и читаемо: with open("friend.json", "w", encoding="utf-8") as f: json.dump(friend, f, indent=2, ensure_ascii=False) # Результат в файле: # { # "name": "Алиса", # "age": 12, # "hobbies": [ # "музыка", # "игры" # ] # }

json.dumps() — превращаем в строку

json_string = json.dumps(friend, indent=2, ensure_ascii=False) print(json_string) # Выводим JSON как строку

games = [ {"name": "Minecraft", "rating": 9.5, "genre": "песочница"}, {"name": "Among Us", "rating": 8.0, "genre": "детектив"}, {"name": "Roblox", "rating": 7.5, "genre": "платформер"} ] # Сохраняем каталог в JSON with open("games.json", "w", encoding="utf-8") as f: json.dump(games, f, indent=2, ensure_ascii=False) # Читаем каталог обратно with open("games.json", "r", encoding="utf-8") as f: loaded_games = json.load(f) for game in loaded_games: print(f"{game['name']} — {game['rating']}/10 ({game['genre']})")

🎮 Практика: создаём базу данных

Соберём всё вместе! Создадим программу для управления базой данных друзей с сохранением в JSON.

База данных друзей

import json import os DB_FILE = "friends.json" # Загружаем базу (или создаём новую) def load_friends(): if os.path.exists(DB_FILE): with open(DB_FILE, "r", encoding="utf-8") as f: return json.load(f) return [] # Сохраняем базу def save_friends(friends): with open(DB_FILE, "w", encoding="utf-8") as f: json.dump(friends, f, indent=2, ensure_ascii=False) # Добавляем друга def add_friend(name, age, hobby): friends = load_friends() friends.append({"name": name, "age": age, "hobby": hobby}) save_friends(friends) print(f"✅ {name} добавлен!") # Показываем всех друзей def show_friends(): friends = load_friends() if not friends: print("База пустая") return for i, friend in enumerate(friends, 1): print(f"{i}. {friend['name']}, {friend['age']} лет, хобби: {friend['hobby']}") # Главное меню while True: print("\n1. Показать друзей 2. Добавить 3. Выход") choice = input("Выбор: ") if choice == "1": show_friends() elif choice == "2": name = input("Имя: ") age = int(input("Возраст: ")) hobby = input("Хобби: ") add_friend(name, age, hobby) elif choice == "3": break
🔑 Что здесь происходит:

1. os.path.exists() — проверяем, существует ли файл базы

2. load_friends() — загружаем базу из JSON (или создаём пустую)

3. save_friends() — сохраняем изменения обратно в JSON

4. Данные не теряются между запусками программы!

students = [ {"name": "Анна", "age": 12, "grade": 85}, {"name": "Борис", "age": 13, "grade": 92} ] with open("students.csv", "w", encoding="utf-8", newline="") as f: writer = csv.DictWriter(f, fieldnames=["name", "age", "grade"]) writer.writeheader() # записываем заголовок writer.writerows(students) # записываем все строки
CSV vs JSON:

CSV — простой, как таблица Excel. Подходит для плоских данных (без вложенности).

JSON — более гибкий. Поддерживает вложенные структуры (списки внутри словарей).

Для большинства задач в Python JSON удобнее.
