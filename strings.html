📚 Что такое строки?

Строки в Python — это последовательности символов, заключённые в кавычки. Они используются для хранения и обработки текста.

# Создание строк name = "Алиса" greeting = 'Привет!' text = "Это строка на Python"

Особенности строк:

✅ Строки неизменяемы — после создания нельзя изменить отдельный символ

✅ Строки могут содержать любые символы: буквы, цифры, спецсимволы

✅ Пустая строка тоже является строкой: ""

📍 Индексация строк

Каждый символ имеет свой индекс. Индексация начинается с 0!

✂️ Срезы строк

Срезы позволяют получить подстроку. Синтаксис: строка[начало:конец:шаг]

text = "Python" print(text[0:3]) # Pyt (с 0 по 2) print(text[:3]) # Pyt (с начала до 3) print(text[3:]) # hon (с 3 до конца) print(text[::2]) # Pto (каждый второй) print(text[::-1]) # nohtyP (перевернуть)
💡 Важно:

Конец среза НЕ включается! Шаг по умолчанию равен 1. Отрицательный шаг идёт с конца.

✨ f-строки
